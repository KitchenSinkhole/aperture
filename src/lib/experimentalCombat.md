## experimentalCombat.ts

**Purpose:** Default combat-ring duration constant when device prefs are unavailable (SSR/tests).
**File:** `src/lib/experimentalCombat.ts`

### COMBAT_RING_MS
Default ring length in milliseconds (derived from `DEFAULT_EXPERIMENTAL_COMBAT_RING_MINUTES`). Live UI reads minutes from `experimentalCombatRingDuration.ts`.
